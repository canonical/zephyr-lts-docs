# Cross-version reference allowlist for check-version-leak.
#
# Each entry pins one legitimate mention of a YY.MM release version
# outside the current release family (DOC_VERSION, DOC_VERSION.N and
# SOURCE_TAG, from versions.env) to one built HTML page. The check scans
# docs/_build/ after `make html` and fails on any un-allowlisted hit.
# "Version" here means any YY.MM token with month 01-12; interim
# releases (26.10), other LTS releases (24.04), and RC/patch-suffixed
# variants (26.04-rc1, 24.04.1) are all in scope.
#
# Format: <relative-html-path>:<trimmed-line-content>
#   * paths are relative to docs/_build/
#   * blank lines and lines starting with # (after optional
#     whitespace) are ignored; entry content may contain '#' freely
#   * whole-trimmed-line match, so if the underlying rendered content
#     changes shape the check re-fires and forces this list to be
#     re-reviewed
#
# When the referenced release is eventually retired upstream (e.g. the
# 24.04 SDK tracks are dropped from the zephyr-sdk-ng snap), the
# matching entries below become stale and should be removed together
# with the prose that produced them.
